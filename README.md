# Precios Voy y Vuelvo

Catálogo de precios con foto para el personal de las botillerías Voy y Vuelvo y Voy y Vuelvo 2.0.

- `index.html` se genera automáticamente desde la planilla de precios (Google Sheets) con `build/build.py`. No editarlo a mano.
- `img/` fotos de productos; `data/fotos.json` asocia cada producto con su foto.
- Los costos de la planilla nunca se publican aquí.
